# LLMagnet PRD(产品需求文档)

版本:v1.0 · 2026-08-30 · 状态:Phase 0 待执行
本文档记录项目的前因后果、全部关键决策及其理由,是新成员(人或 agent)理解本项目的第一入口。

---

## 1. 一句话定义

**LLMagnet = 「输入:开源权重 LLM + 现成 agent;输出:隐空间 agent」的编译器框架。**
它把 agent 的推理循环、工具触发、记忆读写从"明文 token 脚手架"搬进模型隐空间,只在最终答案处落地文字;并以可验证奖励的 RL 闭环让它越用越准,终局形态是带外部锚的自进化系统,目标载体是机器人。

## 2. 前因后果(项目是怎么长出来的)

这个项目不是拍脑袋设计的,而是从一次 AI memory 领域调研中逐层推演出来的,链条如下:

1. **起点:AI memory 框架调研**(2026-08)。调研结论:外置记忆四大架构(扁平抽取式 Mem0 / 知识图谱式 Zep / 文件系统式 Letta / 分层 OS 式 MemOS)竞争激烈但跑分互有争议;参数化(ROME/MEMIT/WISE/GRACE)与潜空间(MemoryLLM/M+/Titans)是"内置到 LLM 里"的另外两条路线,工业未落地。
2. **关键洞察:四合一设想**。用户注意到四个互缺一角的进展:
   - Claude Fable 5 系统卡证实模型存在 **J-space 潜空间推理**(illegible reasoning,中间步骤不落地成文字);
   - Coconut/LatentMAS 证明**取消明文思考、最后一步映射成文字**在训练上可行;
   - 微软 Mage-VL 提供了**码流原生的实时流式感知**(且其记忆管理刻意极简,留下明确空位);
   - 用户提出**"前空间触发层"**:记忆读回路径兼作潜空间的唤醒/工具意图/停止判定门。
   四者组合 = 把 Anthropic 在 Fable5 中"观察到的工作空间现象"做成显式可训练机制。
3. **工程收口:fork 回注**。工具参数必须落地明文(外部接口是文本),但可 fork 侧分支执行工具、把结果编码回隐状态注回主循环——对主循环而言工具 I/O 也"不落地"。明文降级为纯传输编码。
4. **学习闭环:RL 范式**。Agent Lightning 证明"训练器解耦挂载、轨迹归约 transitions、AIR 中间奖励"可行;本项目的 agent 决策(触发/停止/记忆)以此为范式进入权重。
5. **终局雄心:自进化**。Absolute Zero 与 Darwin Gödel Machine 证明"自己做数据自己训自己"在可验证域成立;本框架补齐数据环/权重环/记忆环,缺任务发生器与外部锚。
6. **落地载体:机器人**。用户明确最终用于机器人——这让隐空间循环从"省钱的选项"变成"物理必需"(控制回路 10-200Hz,文字跟不上),Figure Helix 的 S2→S1 隐向量交接是行业先例。
7. **务实启动:个人级 MVP**。全套框架太大,先在单卡 3090 上用 1.5B 模型验证四个核心假设(见 §5),agent 层用户指定采用 dsh(一切皆插件)。

## 4. 系统架构

### 4.1 终局形态(agent 编译器 + 薄运行时)

```
输入:开源权重 LLM + 现成 agent(工具定义 + 任务集 + 奖励函数)
  -O0  原样输出(文本 agent,基线)
  -O1  CoT 蒸馏:文本思维链 → 隐空间循环(Coconut 式)
  -O2  工具 I/O 编译:调用点 fork + 结果编码回注(ICAE/RCC 式)
  -O3  端到端 RL:触发门/停止/记忆读写进权重(Lightning 范式 + AIR)
输出:agent.compiled.pt + manifest.yaml(能力边界)+ 薄运行时 + 审计探针
```

运行时数据流(对主循环"不落地"):

```
感知(码流原生,机器人=相机流)
  ↓
三合一触发层(工具意图 + 记忆读回兼唤醒 + 停止判定)← 项目最核心创新点
  ↓
隐空间推理循环(最后一步才映射成文字)
  ↓ ↘ 高 surprise 内容回写记忆
fork ──→ 参数序列化成明文(唯一落地处,留审计日志)──→ 执行工具/动作
  ↑ ←── 结果明文 → 编码回隐状态 → 注回主循环
```

### 4.2 MVP 形态(当前)

```
vLLM(Qwen2.5-1.5B,OpenAI 兼容端点)
        ↑
dsh(DeepSeek Harness):工具插件(calculator/kb_query)+ agent 循环
        ↑
runner_dsh.py(Python SDK 驱动,逐任务 run → judge 判分 → traces/metrics)
        ↑
任务集:算术组合/查表/两跳,300 训练 + 50 封存金标,程序判分
```

## 5. 四个核心假设(全部实验的主线)

| # | 假设 | 文献坐标 | 验收标准 | 对应大框架部件 |
|---|---|---|---|---|
| H1 | 明文 CoT → 隐空间循环,质量不降、token 大降 | Coconut / LatentMAS | 质量掉幅 ≤2%,token 降 ≥30% | forge/distill(-O1) |
| H2 | "要不要调工具"在隐状态里线性可读 | arXiv:2605.14038 | 探针 F1 ≥ 0.8 | rt/gate(触发层) |
| H3 | 工具结果编码回隐状态,质量保持 | ICAE / RCC / fork 设计 | ≥ 明文注入的 95% | rt/fork_exec(-O2) |
| H4 | 可验证奖励 RFT/GRPO,小模型越调越准 | Absolute Zero / RLVR | 3 轮成功率单调升 | forge/trainer(-O3) |

**证伪也是有效结果**——每阶段在 `mvp/reports/` 留一页"假设 → 数字 → 结论",据此修订大架构。

## 7. 硬性红线(违反即返工)

1. **guardrails/急停/安全层永不编译进隐空间**——机器人场景是物理安全要求,层级独立于一切学习组件,低于 S1 控制频率。
2. **外部锚不可自改**——冻结金标集与奖励函数的修改权在人类;agent 只能优化,不能动尺子。
3. **明文只允许出现在 fork 边界与最终答案**——fork 边界同时是审计日志边界,注入前必须过内容过滤。
4. **自进化数据环必须持续注入真实流量/物理反馈**——自产数据占比上限 0.5,防分布坍缩。
5. **manifest 锁能力边界**——底模血统、训练分布、工具 schema 版本、编译 pass 记录;越界行为无保证。
